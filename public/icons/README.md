# PWA Icons

This folder should contain the following icons:

- icon-192x192.png (192x192 pixels)
- icon-512x512.png (512x512 pixels)

## Icon Requirements:
- PNG format
- Transparent background recommended
- Bus or travel theme
- Simple, recognizable design

## How to create icons:
1. Use any image editor (Photoshop, Canva, etc.)
2. Create square images with the specified sizes
3. Save as PNG with transparency
4. Replace placeholder files

## Temporary Solution:
For now, the app will work without icons, but PWA installation prompts may not appear.
